These tools retrieve context (fragments, commands, prior sessions) and delegate: agent_run launches a configured ctxloom agent as a child session; agent_send carries parent-child messages (children address only "parent"). Manage ctxloom (bundles, profiles, remotes, review, trust, hooks) with the ctxloom CLI in your shell, not tools here. Tasks live in the separate `taskloom` MCP server and CLI.
