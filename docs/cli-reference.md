# ctxloom CLI Reference

The CLI reference is **generated** from the cobra command definitions in
`internal/cli` — it is no longer maintained here. Find it at:

- **Website**: [ctxloom.dev/reference/cli](https://ctxloom.dev/reference/cli/) —
  per-command pages regenerated by `just gen-docs` (source:
  `website/src/content/docs/reference/cli/`)
- **Man pages**: `man ctxloom` (shipped in release archives; `just man-install`
  locally)
- **In-terminal**: `ctxloom <command> --help`

To change the reference, edit the command's `Short`/`Long`/`Example` fields in
`internal/cli` and run `just gen-docs`; CI fails on drift.
