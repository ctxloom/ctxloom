Ask the user whether a tool call may run. Your engine calls this itself, as its permission prompt, when its permissions say to ask; you never need to call it. The call waits while the user decides from their own terminal, and answers with their choice: run it this once, run it for the rest of this session, always run it, or do not. If nobody answers in time, it is denied. A denial carries a message: read it, do not retry the same call unasked, and tell the user what you wanted to run and why.
