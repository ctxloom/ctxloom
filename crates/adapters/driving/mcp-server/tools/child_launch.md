Launch a child of yours: a session of its own, run by the user's daemon, that takes its task as its first turn and stays open between tasks until you close it. Give it its task when you launch it, or send it one after: a child with no task sits idle. To have it work in another ctxloom project, give that project's directory as `project` (relative to your own project's root); it runs there on that project's own config, and only once the user has trusted that project. Prefer children launched this way to your engine's own subagents; each is a recorded, resumable session of its own that the user can see and steer.
