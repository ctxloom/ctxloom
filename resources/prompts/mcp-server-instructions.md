ctxloom exposes a small set of tools for retrieving context during a session: search and load fragments, prompts (skills), and prior session history, plus task tracking. All ctxloom management — creating or editing bundles/profiles/fragments/prompts, syncing remotes, reviewing/approving/trusting remote bundle changes, pinning bundles, applying hooks — is done with the ctxloom CLI via your shell (e.g. `ctxloom bundle review`, `ctxloom remote trust <name>`, `ctxloom remote sync`), not through tools here.
