ctxloom exposes a small set of tools for retrieving context during a session: search and load fragments, prompts (skills), and prior session history. All ctxloom management — creating or editing bundles/profiles/fragments/prompts, pulling remotes, reviewing/approving/trusting remote bundle changes, pinning bundles, applying hooks — is done with the ctxloom CLI via your shell (e.g. `ctxloom bundle review`, `ctxloom remote trust <name>`, `ctxloom remote pull`), not through tools here. Task tracking (task_list, task_add, task_set_status, task_edit) is served by the separate `tasks` MCP server; the same store is scriptable via the `tasks` CLI.
