# The allowed exceptions to `just lint-handoffs` (scripts/handoff-check.sh): an
# in-memory field or static between components that the ast-grep rules
# (scripts/handoff-rules/) find in crates/core/application and crates/root. One
# per line:
#   <file> | <text of the declaration> | <why>
# `<why>` starts `debt:` for a hand-off that is to be replaced by a message (it
# names the inventory row of .plan/messages-only.plan.md, `N` the second sweep's,
# and the pattern that replaces it); every other entry is a runner's own state or
# test plumbing and says why it hands nothing to another component. An entry
# that covers nothing fails: this list only shrinks.
